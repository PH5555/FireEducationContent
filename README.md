## 📖 About The Project

우리는 학생때부터 의무적으로 화재 안전 교육을 받는다. 예를 들어 영상 시청이나 유인물을 통하여 소화기를 분사하는 법을 배우거나 대형 강의를 통해 교육을 받는다. 하지만, 실질적으로 대비하는 훈련은 손수건으로 입을 막은 후 몸을 숙여 운동장으로 대피하는 훈련뿐이다. 이렇게 이론적인 내용이 주를 이루는 교육속에서 과연 몇명이나 화재가 발생했을 때 당황하지 않고 대처할 수 있을까? 

본 프로젝트는 이러한 문제를 해결하기 위한 효과적이고 능동적인 가상현실 화재 안전 교육 컨텐츠이다. 불이 날 수 있는 다양한 상황을 구현하고, 소화기뿐만이 아닌 우리 주변에 다양한 일상용품으로 유연하게 화재를 진압할 수 있도록 했다.
